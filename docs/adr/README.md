# Architecture decision records

ADRs capture a choice, its evidence and its consequences. A **proposed** ADR invites review; an **accepted** ADR records agreement; a **superseded** ADR points to its replacement. Update progress in the plan or experiment logs, not by silently rewriting a past decision.

For a new ADR use: title; date; status; context; decision; alternatives; consequences; validation/conditions for acceptance; sources. Keep concrete experimental findings in `docs/experiments/` once experiments begin.
